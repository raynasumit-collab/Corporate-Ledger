Data Management

All data is stored locally in this browser (localStorage). Use Export/Import to move data between browsers, or set up GitHub backup below for off-site, versioned backups.

GitHub Hosting & Backup

Store a backup copy of your data (corporate-ledger-backup.json) inside a GitHub repository. Use a fine-grained personal access token scoped to only this repository with Contents: Read and write permission. Your token is stored only in this browser's local storage — it is never sent anywhere except directly to GitHub's API.
